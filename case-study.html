CareerForge AI.

A workspace to move from resume review to a more organized job application process.

I built CareerForge AI to bring several disconnected job-search tasks into one flow: understand a resume, compare it with a role, prepare application materials, discover relevant remote opportunities and track each application.

01THE PROBLEM SPACE

One job search.
Too many separate tasks.

Preparing an application can mean switching between a resume, a job description, a document editor, job listings and a spreadsheet. CareerForge AI is designed as one working space for those steps, so users can keep their profile and applications organized.

01 / UNDERSTAND

What does my resume communicate?

Extract skills and contact details, then review a set of resume-readiness checks.

02 / COMPARE

Where do I fit this role?

Compare resume/profile data with a job description and inspect matched and missing skills or keywords.

03 / ACT

How do I keep moving?

Prepare application drafts, save relevant roles and track progress through a pipeline.

Research honesty: these are the product problem and goals, not claims of completed user interviews. Add user research and validation results only after sessions are run.

02THE USER FLOW

From profile to pipeline.

The core journey is a repeatable sequence: understand your career profile, evaluate a role, prepare a tailored application and record the next action.

04TECHNICAL DECISIONS

A stack chosen for a working product.

AREAIMPLEMENTATIONWHY IT MATTERS
InterfaceReact 19 + TypeScript + Vite

Component-based UI and type-aware development with a modern build workflow.

IdentityFirebase Authentication

Google sign-in, including redirect fallback when a popup cannot be used.

DataFirebase Realtime Database

User records are organised under each authenticated user's UID; rules must be deployed and checked.

Resume textpdf.js in the browser

Extracts selectable text without uploading the original PDF in the inspected implementation.

AI writingFirebase AI Logic + Gemini

AI-written drafts can fall back to templates when AI Logic is unavailable or not configured.

Job feedsJobicy + Himalayas adapter

Provider adapters normalize listings; an authenticated callable handles the Himalayas browser-CORS constraint.

Trade-off: feed availability, provider terms, deployment configuration and candidate eligibility can vary. The current sources cover remote jobs from two providers, not every job board or location.

05WHAT NEEDS VALIDATION

Be clear about the edges.

A credible product story describes limitations as well as capabilities. These are verification points identified in the project's source report.

A

Scanned PDFs

Image-only scanned PDFs are not OCR-processed. Users need a text-based PDF or pasted resume text.

B

AI-generated copy

Users should review and edit AI or template output before sending an application.

C

Job eligibility

Remote does not mean worldwide. Verify eligibility, salary and application details on the original listing.

D

Live services

The project report records that Firebase setup, deployed rules and the live callable integration were not independently verified in that review.
